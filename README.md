# Nodo — Landing Page

Marketing landing page for Nodo, a software development studio (Buenos Aires, Argentina). Single-page site built with vanilla JS and Vite.

## Stack

- [Vite](https://vitejs.dev/) — dev server and build
- Vanilla JS (no framework)

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run preview` — preview the production build locally

## Structure

```
index.html       # single-page markup, all sections
src/main.js       # entry point, wires up page behavior
src/canvas.js     # hero background particle animation
src/style.css     # styles
public/           # static assets
```
